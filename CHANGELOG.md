### Added / 新增
- `skills/x-ops-team-setup/SKILL.md`: bilingual (English / 简体中文) skill that builds an X operations team — nine setup questions, X plugin connection, 3–6 dedicated bots, three reusable skills, scheduled routines, a draft → approve → publish queue, and optional cloud-browser posting with guardrails.
  双语 skill：九个设置问题、连接 X 插件、3–6 个专职 Bot、三个可复用 skill、定时 routines、“草稿 → 审批 → 发布”队列，以及带护栏的可选云电脑浏览器发帖。
- `docs/methodology.md` and `docs/methodology.zh-CN.md`: creator methods, X ranking-signal weights, cloud-browser posting tutorial, 30-day rollout plan, with source links.
  方法论文档（中英）：创作者方法、X 排序信号权重、云电脑发帖教程、30 天计划，均附来源链接。
- Bilingual README, contributing guide, code of conduct, security policy, issue and pull request templates.
  双语 README、贡献指南、行为准则、安全策略、Issue 与 PR 模板。
