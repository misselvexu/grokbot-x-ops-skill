# Security Policy / 安全策略

## English

### Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

### Reporting a vulnerability

**Please do not report security issues in public issues, discussions, or pull requests.**

Report privately via [GitHub Security Advisories](https://github.com/misselvexu/grokbot-x-ops-skill/security/advisories/new) ("Report a vulnerability"). Include a description of the issue, the affected file and step, and how it could be exploited. We aim to acknowledge reports within 7 days.

In scope: instructions in the skill that could cause a bot to leak credentials, bypass human approval, take outward-facing actions unexpectedly, or violate platform rules in ways not disclosed to the user.

### Never share secrets

Never post passwords, 2FA codes, API keys, tokens, cookies, session data, or screenshots of logged-in accounts anywhere in this repository — including issues, pull requests, and advisories. If you have exposed a secret, revoke or rotate it immediately with the provider.

## 简体中文

### 支持的版本

| 版本 | 是否支持 |
|---|---|
| 1.0.x | ✅ |

### 报告安全问题

**请勿在公开的 Issue、讨论区或 Pull Request 中报告安全问题。**

请通过 [GitHub 安全公告](https://github.com/misselvexu/grokbot-x-ops-skill/security/advisories/new)（“Report a vulnerability”）私下报告，并说明问题内容、涉及的文件和步骤，以及可能的利用方式。我们会尽量在 7 天内确认收到。

适用范围：skill 中可能导致 Bot 泄露凭据、绕过人工审批、意外执行对外动作，或以未告知用户的方式违反平台规则的说明。

### 不要分享任何机密

请勿在本仓库的任何地方（包括 Issue、PR 和安全公告）发布密码、2FA 验证码、API key、token、Cookie、会话数据或已登录账号的截图。如果你已经泄露了机密信息，请立即到对应服务商处撤销或更换。
